# Quickstart: التحقق من اختبارات الاستعادة

## المتطلبات
- Node.js 22
- `npm install` مرة واحدة

## الأوامر
```bash
npm run selfcheck
npm run typecheck
npm run lint
```

## النتيجة المتوقعة
- كل اختبارات الاستعادة والدمج تنجح.
- لو سلوك اتكسر، الاختبار اللي بيفشل بيقول اسم السيناريو.

## التحقق اليدوي (بعد النشر، بموافقة)
1. افتح التطبيق، ونزّل نسخة احتياطية.
2. استوردها مرتين بوضع الدمج.
3. تأكد إن عدد السجلات ما زادش، ورسالة الاستعادة بتذكر الشهور والمقالات المتخطاة.
