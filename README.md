# Track Your Sales — by Mahmoud Khairy

تطبيق ويب عربي RTL لمتابعة التارجت والإنجاز الشهري، تسجيل المبيعات، مراجعة التقارير، والرجوع لموسوعة العمل.

## رابط التطبيق

**[افتح Track Your Sales](https://mahmoudkhairyy-cell.github.io/track-your-sales/)**

## الاستضافة والبيانات

- التطبيق يُبنى كملفات Static ويُنشر على GitHub Pages.
- بيانات الموظف التفصيلية (السجلات، الإعدادات، والملف الشخصي) تُحفظ محليًا في متصفح الجهاز باستخدام `localStorage`، ولا تنتقل تلقائيًا بين الأجهزة أو المتصفحات.
- عند توفر اتصال بالإنترنت، يرسل التطبيق ملخص تقرير الشهر الحالي إلى خدمة تقارير المدير؛ لا يُرسل سجل البيانات المحلي الكامل.
- استخدم النسخ الاحتياطي JSON من داخل التطبيق لنقل بياناتك أو الاحتفاظ بنسخة منها.
- مسح بيانات المتصفح أو تغيير الجهاز دون استعادة نسخة احتياطية قد يؤدي لفقد البيانات.
