# Track Your Sales

**Track Your Sales — by Mahmoud Khairy** تطبيق ويب عربي RTL لمتابعة إنجاز المبيعات والتارجت الشهري، مع سجل الإنجازات، التقارير، النسخ الاحتياطي JSON وموسوعة SR.

> أداة مستقلة لمتابعة التارجت الشخصي، وليست منتجًا رسميًا أو معتمدًا من Orange.

## النسخة المنشورة

يتم نشر التطبيق كـ **Static Export على GitHub Pages** من الفرع `local-version`:

https://mahmoudkhairyy-cell.github.io/track-your-sales/

ملف النشر: `.github/workflows/pages.yml`. لا يعتمد مسار النشر على Vercel أو قاعدة PostgreSQL لتشغيل الوظائف المحلية الأساسية.

## تخزين البيانات والمزامنة

- بيانات الموظف والإعدادات والسجلات الأساسية تُحفظ محليًا في متصفح/جهاز المستخدم عبر `localStorage`.
- لذلك البيانات المحلية لا تنتقل تلقائيًا بين الأجهزة أو المتصفحات. استخدم **المزيد ← تصدير JSON** للاحتفاظ بنسخة احتياطية، والاستيراد بعد مراجعة ملخص النسخة.
- تقارير المدير/الفرع تعتمد على تكامل Supabase Edge Function منفصل عند تهيئته. هذا التكامل لا يعني أن كل بيانات التطبيق محفوظة سحابيًا.
- لا تضع مفاتيح سرية أو ملفات `.env` أو نسخ JSON الاحتياطية داخل المستودع العام.

## التشغيل محليًا

يتطلب Node.js 22 أو إصدارًا متوافقًا:

```bash
npm install
npm run dev
```

## فحوصات الجودة

```bash
npm run selfcheck
npm run typecheck
npm run lint
npm run build
```

- `selfcheck`: اختبارات مستقلة للحسابات والكميات والتحقق من النسخ الاحتياطي ودمج السجلات، ولا تحتاج قاعدة بيانات.
- `typecheck`: فحص TypeScript.
- `lint`: فحص ESLint.
- `build`: إنشاء نسخة Static Export داخل `out/`.

## قواعد حساب أساسية يجب الحفاظ عليها

- كل KPI له وزن وتارجت: أقل من 90% لا يساهم في الإجمالي، وعند 90% يبدأ احتساب مساهمته.
- المؤشرات الفردية لا يوجد لها سقف 200%.
- سقف إجمالي الإنجاز الشهري 200% فقط.
- New Orange Cash وزنه 0%، لكنه شرط مستقل لاستحقاق الكوميشن: عدد المحافظ الجديدة لا يقل عن 90% من عدد New Lines.
- لا يُحتسب الكوميشن إلا بعد تحقق شرط المحافظ ووصول الإجمالي النهائي إلى 80% على الأقل.
- لا يوجد خصم إضافي للـ Postpaid أو DSL.

## ملفات مهمة

- `src/app/(app)/`: صفحات التطبيق.
- `src/lib/calculations.ts`: قواعد الحساب والتارجت والكوميشن.
- `src/lib/local-api.ts`: التخزين المحلي ومسارات البيانات.
- `src/lib/sync.ts`: رفع تقارير المدير الاختيارية.
- `public/sw.js`: دعم العمل دون اتصال وكاش ملفات التطبيق.
- `.github/workflows/pages.yml`: فحص وبناء ونشر GitHub Pages.

لا تحذف بيانات المستخدم أو تغيّر قواعد الحساب عند تحديث التصميم. اختبر الحسابات أولًا، واحتفظ بنسخة JSON قبل أي تغيير كبير.
