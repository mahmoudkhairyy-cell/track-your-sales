# Spec Kit (تطبيق يدوي)

الملفات دي منسوخة من `github/spec-kit` (commit `2ee2b1e`) عشان نستخدم أوامر Spec Kit مع Claude في المشروع ده.
الأوامر موجودة في `.claude/commands/` (مثلاً `/speckit.specify` و`/speckit.plan` و`/speckit.tasks`).
السكريبتات موجودة في `.specify/scripts/bash/` والقوالب في `.specify/templates/`.

ملاحظة: الملفات دي اتنسخت يدوي بدل `specify init` لأن الأداة مش متاحة في البيئة اللي اتعمل فيها الربط.
